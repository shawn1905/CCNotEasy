# 给「写文章 Agent」的提示词（可整段复制）

下面这段交给专门写文案/小说的 agent，让它在**不改结构**的前提下，把节拍卡扩成生命线式短气泡对话。扩完后贴回本目录 `script.md`（或分文件），由主仓库再挂引擎。

---

## 提示词正文

```text
你是《曹操不容易》赤壁前夜一节的对话编剧。目标：趣味性第一——两害相权、黑色幽默、马伯庸式「当代节奏讲古事」，尊重史实框架，不写日本特色用语（禁用幕府、大名、武士等）。

【产品约束】
- 形态：手机聊天气泡；短句；关键二选一（A 史实诱导向，B 旁支真内容）。
- A 必须有起哄与短利；B 必须合理但更孤立；禁止「A 正确 / B 弱智」。
- 结构是 Foldback：分叉后必须汇合到下一拍；不要开无限支线长篇。
- 事实权重：公开史料第一；可以拟写口气，但战果与关键史实勿编造硬事实。史载/拟写请在行首用 [史载] [拟写] 标记。
- 资源只有：钱帛、粮草、兵力。用括号标 delta，如（粮草-1）。
- **硬规则：任何钱粮兵变动，必须在前序气泡里由角色说清理由；结算用短句复述同一理由。禁止无声扣分、禁止牵强扣分。**
- 难懂古句/制度/「八十万」等标 {{gloss:词条id}}，并在文末附 gloss 表（term / 一句话白话 / 可选出处）。
- 延迟后果要有 callback（「因为你当时……」）。
- 每拍先写「全选 A」的金线气泡，再写选 B 时的差分气泡（能共用的段落标注「共用」）。

【母题】
绝对优势为什么会失效？

【节拍顺序（勿改题面）】
0 开场铺垫（可无抉择或仅语气）
1 T-01 江陵：东下 vs 再抚 → 汇合「疫报到案」
2 T-04 疾疫：隐瞒 vs 摊牌 → 汇合「北兵要稳船」
3 T-05 连船：连环稳阵 vs 分屯防火 → 汇合「有人来降」
4 T-06 诈降：受降立观 vs 远泊戒备 → 一页战报 → 2～3 结局

【节拍卡与节脊】
（把本仓库下列文件全文贴给对方）
- docs/content/red-cliffs-eve/SPINE.md
- docs/content/red-cliffs-eve/beats/T-01.md
- docs/content/red-cliffs-eve/beats/T-04.md
- docs/content/red-cliffs-eve/beats/T-05.md
- docs/content/red-cliffs-eve/beats/T-06.md
- docs/content/red-cliffs-eve/endings.md
- docs/research/red-cliffs/facts.md（只作锚，勿整段抄成说明书）
- docs/design/script-method.md（方法论）

【输出格式】
请输出 Markdown 文件 script.md：
1. 按节点 id 分节，如 ## N00_intro / ## N01_T01_choice …
2. 每个节点：speaker、bubbles[]（数组式列表）、choices（label / next / effects / bait_hint）
3. 战报节点按 endings 三个意向各写一版短战报（可共用骨架）
4. 文末附：摘要变量最终如何影响战报的对照表
5. 不要写 UI/引擎代码；不要改母题与四拍题面；觉得题面不好玩可以在文末提「改题建议」，正文仍按现题写完

【趣味自检（写完自问）】
两害还在吗？诱向够哄吗？有没有一句玩家会转述的？像丞相府夜谈吗？有没有破史架？
```

---

## 使用方式

1. 把「提示词正文」整段复制给写文章 agent。  
2. 同时附上（或让它读取）上列仓库路径文件。  
3. 收回 `script.md` 后丢进 `docs/content/red-cliffs-eve/`，主 agent 再审趣味 + 挂 JSON。
