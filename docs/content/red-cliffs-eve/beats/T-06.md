# 节拍卡 T-06 · 诈降：受降立观 vs 远泊戒备

| 项 | 内容 |
|----|------|
| 事实锚 | F-12（黄盖诈降、火船） |
| 戏剧问题 | 来降的船——你出营立观邀功，还是当它可能是火种？ |
| 场景形态 | 密信急变 + 军事 |
| 汇合出口 | 一页战报 → 结局 |

## 两害

| | A 史实诱导向 | B 旁支真内容 |
|--|--------------|--------------|
| 意向 | 受降、近泊、丞相（或代者）观阵——短利「不战而下」 | 斩使或远泊强弩、隔岸点名验船——火攻流产或大打折扣 |
| 谁起哄 | 「盖有宿怨于瑜，降诚也」；求功者跪一排 | 「东南风起时，降船最像火种」；少数扫兴者 |
| 短利 | 可能立刻少打一仗的幻觉；威望表演 | 当场得罪、像多疑暴君；若防住则「赢得很丑」 |
| 资源 | A：战报阶段再结算火伤（须在战报里写清烧了什么） | B：可能 **粮草-1**（远泊多耗巡哨）或 **钱帛-1**（赏弩士加岗）；火伤低 |
| 理由（必说） | 战报：连环船营被烧 / 岸仓被延烧——逐项报损 | 将领：船不靠岸，巡哨加夜油与弩矢，先从账上支 |

## 即时半回执

- A：鼓乐将作；有人已拟受降文书标题——风突然贴脸。  
- B：弩机上弦；降船停在弓矢射程外——帐内骂你「疑神疑鬼」。

## 选择审计

- 本节最大真赌注：必须读回，禁止静默同结局
