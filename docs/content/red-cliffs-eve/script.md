- [拟写] **管粮吏：** （把算筹敲在案上）降兵名册还是潮的。仓满，不代表人心满。  
- [拟写] **谋士：** 给江东的信可以今晚就写。写狠一点，他们自己会抖。  
- [拟写] **管粮吏：** 若立刻开拔——我得先扣掉沿江一旬的漕运粮，船队才吃得动。（看你）这是账，不是怯。  
- [拟写] **府吏：** 若再留些日子安顿降人：酒肉、赏钱、给降将安家——钱帛要先抛出去，才能换他们少在夜里磨刀。
