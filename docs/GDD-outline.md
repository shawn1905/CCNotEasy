## 1. 定位

| 项 | 定案 |
|----|------|
| 作品 | 《曹操不容易》（CCNotEasy） |
| 卖点 | **两害相权**——没有干净解 |
| 调性 | 严肃考据 + 逻辑展开为主；幽默 ≤ 1/10；**中国风用语**（禁日本特色词） |
| 受众 | 史粉 + 叙事抉择为主，策略适中 |
| 结构 | 叙事可贯一生；**单节 10–15 分钟**；本切片只做一节 |
| 平台 | 网页；**手机优先**；本切片不做桌面包 |
| 联网 | 本切片纯单机本地存档 |

## 2. 本切片玩法（赤壁前夜）

- **形态**：对话游戏（纯 UI + 文字）
- **主循环**：事件呈现 → 两害抉择 → 资源变化（钱帛/粮草/兵力）→ 下一事件；战时为**选方略 → 一页战报**
- **场景类型可用**（本切片按需抽样，不求九类全开）：朝会/请托、密信/急变、府议、战报结算、用人/赏罚、钱粮/屯田、邦交/结盟  
  - 科研、制造：**本切片不做**
- **决策域**：军事、内政、用人、邦交、后勤
- **史实策略**：大框架忠于史；允许 what-if。用引导/暗示**诱向史实选项**；**旁支才是真内容**，旁支结局**不必快乐**
- **结局**：本节内给出可感知的分支收束；并暗示生涯多结局体系（忠汉/称王/身死/被架空等）的种子，不在本切片做完全生涯

## 3. 本切片明确不做

联机、MOD、成就、排行榜、桌面包、立绘/大地图/ASCII 特效、科研制造玩法、纪传体跨线影响。

## 4. 产品级已确认、但不进本切片工程（或只留接口）

| 项 | 说明 |
|----|------|
| 势力 AI（扩地/出征） | 产品要做；切片可用**脚本化对手态度**占位，接口预留 |
| 真 LLM 推演 | 产品要做；切片可先**可选调用**（无 key 则本地稿），不阻塞对话骨架 |
| 一生叙事 / 纪传体宇宙 | 远期；本仓库先只服务曹操篇切片 |

## 5. 视听

- UI：Omarchy 感（暗色、方正、顶栏/面板/终端感），手机优先  
- 音：UI 音效 + 一套古意 BGM（可用免版税素材占位）  
- ASCII 特效：后置  

## 6. 技术（剧本通过后再挂）

- Vite + TypeScript + React + Tailwind（见 `docs/design/architecture.md`）  
- 事件 JSON；本地存档；Tokyo Night  
- **顺序：** 节脊 → 节拍卡 → 对话本 → 再脚手架（见 `docs/design/script-method.md`）

## 7. 验收（本切片）

1. 手机浏览器可玩完一节 10–15 分钟  
2. 至少 1 条「史实诱导向」路径 + 1 条「旁支真内容」路径可走通  
3. 三条资源可见变化；至少一次战报结算  
4. 有简易音效/BGM 开关  
5. 文案中国风、无日本特色用语
