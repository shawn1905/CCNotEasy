# 用户提供材料

把你发来的史料、笔记、截图转写放这里。

命名建议：`YYYYMMDD-简题.md` 或原文件名。  
文首加：

```
来源：用户提供
收到时间：（Asia/Shanghai）
用途：facts / tensions / 文案口吻 / 其他
```

优先于网页二手综述入库。

## 权重约定

1. **公开严肃史料**（`red-cliffs/`、`sources/`）— 事实第一  
2. **朋友材料**（如 `易品三国_解构/`）— 看法与调性第二；与史实冲突时让位第 1  
3. 其余二手/演义 — 仅作钩子，须标明
