# 正史疆域与出处

## 正史疆域 · 37 帧

从 183 年黄巾前夜到 280 年西晋平吴；每帧有势力色块、史事据点与出处。这里只保留标题、说明与出处键。

| 时间 | 标题 | 说明 | 出处键 |
|---|---|---|---|
| 183 年 | 黄巾起事前 · 东汉州郡 | 洛阳为京师，图示主要州郡仍属东汉。河西、辽东和交趾都纳入地图，山地与边部的官府控制有深浅之别。 | han、geo、geoJing、geoFrontier |
| 184 年春夏 | 黄巾起义 · 郡县同时告急 | 黄巾在多地起事。着色沿用汉郡范围，正面交战和起义地点以朱色标出。 | han、cao |
| 184 年冬 | 广宗、下曲阳战后 · 冀州赡饥 | 主要州郡仍依汉郡着色。皇甫嵩随后奏请以冀州一年田租赡济饥民，灵帝准许。此期西北仍有战事。 | han、huangfu309、gucheng309 |
| 185 年春 | 大疫与洛阳宫火 · 加征田钱 | 正月大疫。南宫失火后史载田亩每亩征十钱，注文记为修宫。与此前冀州田租赡饥各有适用范围。 | han |
| 188 年春夏 | 刘焉陈议 · 朝廷置州牧 | 刘焉领益州牧，黄琬领豫州牧，刘虞领幽州牧。州郡授任仍在东汉名义之下。 | han、liuyan312、yi、zztj312 |
| 189 年秋 | 洛阳召兵 · 外军入卫 | 入卫与控制京师发生于同一时期的不同阶段。现以东汉名义保持州郡总览。 | zztj312、dong313、han |
| 190 年 | 讨董 · 朝廷西迁，州郡分据 | 此时领汉官号与掌握地方兵权可以并存。袁绍所在勃海一隅及多头相持的大区，以示意点和浅色表达。 | hou、cao、yuan、liao、yi |
| 191 年春 | 孙坚入洛 · 幽州辞尊号 | 洛阳及近郊的斜线表示此时短暂易手和交错的控制范围。孙坚入洛为军事实进，未据洛阳久守。其他各地沿用上一期可考的大势。 | zztj316、wu1、liuyu317、tianchou317 |
| 193 年冬 | 幽州交兵 · 长安奉献帝 | 斜线示幽州内部交战与政令不一，界线仅示概况；193 年其他地区沿前期形势及可考变动标记。 | liuyu317、zztj316、tianchou317 |
| 194 年末 | 徐州交刘备 · 兖州仍在拉锯 | 曹操与吕布争兖州，着色侧重吕布、张邈当时所得一带；曹军仍守鄄城、范、东阿等处。同年陶谦病卒后刘备接领徐州。 | cao、liu、taoqian321、yuan、liao、shi |
| 195 年 | 曹操复兖州 · 吕布东走 | 本期以曹操逐步收复兖州、吕布东投后为观察点。徐州后来的易手另见 196 年。 | lvbu322、liu、cao |
| 196 年秋冬 | 曹操迎帝至许 · 孙江东立足 | 许县成为奉帝的政治中枢。孙策的江东根基逐渐成形，豫章尚未并入此期孙氏范围。 | cao、hou、liu、wu1 |
| 197 年 | 袁术称帝 · 徐淮婚议 | 沿用上一期所见的主要州郡控制范围，以史点标示徐州与淮南的婚议。 | lvbu322、marriage324、cao |
| 198 年秋 | 高顺破小沛 · 曹操将东征 | 小沛失守先于曹操亲征。州郡色块维持前期范围，小沛军情以史点标明。 | liu、cao、lvbu322 |
| 198 年冬 | 曹操围下邳 · 吕布败亡 | 按建安三年冬纪年着色，标出吕布败亡后的徐州控制范围。史籍对围城时长记述有别。 | cao、lvbu322、liu、xunyou329 |
| 199 年 | 刘备受命截袁 · 徐州军符 | 本期取刘备受命时点。袁绍于同年春并公孙瓒，辽东仍由公孙度经营。刘备此后与曹操分裂，属于同年后续。 | liu、yuanshu332、cao、liao |
| 199 年冬 | 徐州易旗 · 车胄与刘备 | 本期按截袁之后、曹操东征之前着色。列传记先后，具体月份未详。东海昌霸反曹，郡县多响应刘备。刘备其后遣孙乾与袁绍连和。刘岱、王忠初击未克，建安五年春曹操东征；其后关羽为曹操所得，刘备奔袁绍。 | liu、guanyu333、sunqian335、cao |
| 200 年春 | 白马解围 · 沿河迁民 | 建安五年春夏白马、延津战事。州郡色块示意，沿河战线有进退。 | cao、liu、guanyu333 |
| 200 年秋 | 官渡相持 · 河北与中原对峙 | 官渡一役是军事胜负的转折，袁氏的河北郡县此时仍在图上，后续数年才相继归曹。 | cao、yuan、liu、wu2、liao |
| 207 年冬 | 曹操平河北 · 辽东仍自守 | 曹操控制北方主要郡县，江东、荆州、益州、汉中与关右仍各有实际势力。鲜卑、乌桓等北缘控制范围为留白。 | cao、liao、yi、yuan |
| 208 年赤壁前 | 刘琮降曹 · 曹军到江陵 | 赤壁战前的荆州迅速分裂。江夏沿江部分以孙刘会兵区示意，荆南诸郡尚在易手过程。 | cao、liu、wu2、yuan |
| 209 年江陵相持 | 曹仁守江陵 · 周瑜攻南郡 | 本帧取江陵尚由曹仁守、城外交战的阶段。斜线表示南郡控制交错。荆南诸郡在这一时期陆续易手。 | lumeng、wu2、liu |
| 210 年 | 赤壁之后 · 孙刘分据荆州 | 从赤壁结束到江陵归属再议，历时跨年。此帧概括孙刘在长江中游重新分布后的形势，江夏以两部表现长期争夺。 | liu、wu2、lumeng、cao |
| 214 年夏后 | 成都出降 · 刘备接领益州 | 刘备从荆州向西取得蜀地。汉中仍在张鲁手中，荆州也尚未完成下一年的湘水分界。 | liu、yi、liao、wu2 |
| 215 年末 | 刘备取蜀 · 湘水分荆州 | 江夏、长沙、桂阳东属孙权，南郡、零陵、武陵西属刘备。南中此时为益州所属的边远郡县，官府控制有强弱。 | liu、cao、liao、wu2 |
| 219 年冬 | 刘备取汉中 · 孙权袭荆州 | 刘备赢得西边的汉中，却失去长江中游的荆州大部。东向道路的变化与新一轮孙刘冲突相关。 | liu、cao、wu2、lumeng |
| 220 年末 | 魏平河西 · 四郡复定 | 建安末河西诸郡关系错杂。是年夏，苏则救武威后围破张掖，酒泉黄华请降。敦煌经张恭出兵牵制酒泉、接应太守尹奉，接通东边。地图以本年末范围示意。 | hexi220、fei、geoFrontier |
| 221 年 | 魏汉先后称帝 · 孙权受封吴王 | 北方的曹氏控制转为曹魏，成都立汉。孙权此时尚未称帝，东南继续以孙氏江东表示。 | fei、liu、wu2、shi |
| 222 年秋 | 夷陵既胜 · 魏军南向 | 秋魏出兵洞口、濡须、南郡。斜线标示江陵一带战事，城池仍在吴手。 | luxun、wu2、liu |
| 223 年秋 | 夷陵战后 · 蜀汉南中起事 | 夷陵战后，荆州中游仍主要由吴控制。南中以地方势力着色，蜀吴于 223 年复交。 | shu、liu、wu2、dengzhi |
| 225 年冬 | 诸葛亮南征 · 蜀再辖南中 | 南中重归蜀汉统辖。边远地方的实际控制仍有深浅，地图以郡县层面的概况着色。 | shu、wu2 |
| 229 年秋冬 | 魏、蜀、吴三国鼎立 | 三国均已称帝。辽东仍有公孙氏，北缘诸部与西南腹地不按今日疆界涂色。 | shu、wu2、liao、shi |
| 238 年秋后 | 曹魏并辽东 · 北方海岸改属 | 辽东加入曹魏范围，三国对峙继续。辽东、乐浪的着色范围仅反映主要郡治及其附近。 | wei、liao |
| 263 年冬 | 魏灭蜀 · 与孙吴并存 | 曹魏并入蜀汉故地，孙吴仍控制长江中下游和东南。南中与交趾一带的接管和争夺延续至后年。 | wei、shu、wu3、tao |
| 265 年末 | 晋代魏 · 北方与巴蜀换国号 | 西晋承接曹魏及其已取得的巴蜀，孙吴继续独立。纪年按通常所称 265 年末列示。 | jin、wei、tao |
| 271 年 | 陶璜复取交趾 · 晋吴对峙 | 交州南部经过多年争夺，陶璜复取交趾。荆州与长江下游仍是晋吴之间的主要战线。 | tao、wu3、jin |
| 280 年春 | 西晋平吴 · 三分结束 | 司马炎所建的西晋完成平吴。263 年魏灭蜀、265 年晋代魏、280 年晋灭吴是三个不同的版图节点。 | jin、wang、wu3、jinGeo |
