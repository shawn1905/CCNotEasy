## 对本项目最有用的部分

1. **故事逻辑总纲**（`02_故事逻辑/01_故事逻辑总纲.md`）  
   - 内核与我们一致：结构逼人做选择，不是英雄打天下。  
   - **史实 / 创作 / 演义三色分离** → 直接进文案规范。  
   - 赤壁剧本戏剧问题：**「绝对优势为什么会失效？」** → 可作「赤壁前夜」母题句。

2. **荆州史线 7 节点**（`jingzhou_route.json` + `02_史线与推演.md`）  
   - 与第一切片时间重叠的是前 2 节：长坂南撤、夏口与赤壁。  
   - **注意：现成推演多是刘备/孙刘视角**；曹路线要把同一缺口翻成丞相府题面（我们已有 T-01…T-08）。

3. **长坂推演**（`studies.json` → `changban`）  
   - 题面「保军 vs 照应随行」可对照曹侧「轻骑追击深度 vs 辎重/疫病风险」（见 `tensions.md`）。

4. **因果变量表**（粮、军令、名分、信息、关系、民心/世族、忠诚）  
   - 比我们当前三资源（钱帛/粮草/兵力）更细；第一版仍锁三资源，后期可从这里扩「名分/信息」。
