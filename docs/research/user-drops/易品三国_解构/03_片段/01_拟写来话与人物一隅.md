# 片段

## 片段 · 拟写来话与人物一隅

这些句子是游戏里最容易直接借用的“人味”。它们都标“拟写”，不是史书原话，也不改写战果。

### 来话

- **里吏来话（拟写）**：“有人已经把户籍卷在衣襟里，想趁道路还通时走。也有一家来问，能否先在城里分些米，因为祖母走不了这段路。”
- **里吏来话（拟写）**：“有人回来才看见旧田已经长满蒿草。邻里肯轮借一头牛，只怕趁得上耕，趁不上分种。”
- **军吏与里吏来话（拟写）**：“军中在等饷，刚复业的人家也想留些谷过日子。两边都来问，现有这仓谷能撑到几时。”
- **白马来户（拟写）**：“一家把旧地契收在衣箱底，想等太平回去认田界。另一家在这里借到了织机，想让孩子先有个住处。”
- **两户来话（拟写）**：“一家还留着旧门钥匙，想回去看看田界还能不能认出。邻家在这里借了织机，孩子已有了伴，愿先把这一季过完。”
- **一户来话（拟写）**：“一位妇人带着几卷没织完的麻布，托里吏问能不能先借一张席，让年长的家人歇一晚。”
- **运夫来话（拟写）**：“赶车人认得再往前的一段路。他问，若留在这里，能不能先寄口信到收粮城，免得那里仍按旧日子等粮。”
- **县吏与转运卒来话（拟写）**：“郡仓能凑一车，乡里盼今后少缴几回钱。军中若先拿了粮，县里的账还认不认这张约？”
- **军中来话（拟写）**：“弟兄们都听营吏点名。有人愿跟到后营，也有人只想把熬过这一冬的消息捎回家。”
- **押车老卒来话（拟写）**：“久没回家了。前头弟兄等这车谷，队里人却怕回来时少一张脸。”
- **仓吏来话（拟写）**：“军中来催粮，里中也来了人。仓里的谷要先拨去哪边，两头都在等签。”
- **驿吏来话（拟写）**：“军寨要人盯北边，接纳城也在问这批民户何时能到。有人把种粮放在车底，一路都怕它洒了。”
- **东郡里吏回报（拟写）**：“带走了人，地契还留着。等河岸安稳，再问能不能种回原来那块地。”
- **军吏（拟写）**：“城上的人望着北路。若东面再领走一批守兵，明日换岗该找谁？”
- **县尉来话（拟写）**：“守门的人轮了三夜。如今再募，得先有人教，也得有谷发。”
- **里吏来话（拟写）**：“新登记的人家也在问田。若误了农时，来年怕又要开仓。”

### 人物一隅

- **长坂 · 同行的人**：那个问该看哪面旗的妇人终于到了。她请渡口记名的人再念一遍孩子们的名字，然后才去排领粮的队。
- **官渡 · 粮尽前的信**：营门里有人听过太多次捷报和败报。这一晚，他先问回来的同乡，沿路的伤兵有没有人接。
- **湘水 · 两家的账**：渡船人把停用的旧橹重新找出来。他问边吏，河对岸的亲戚是不是也收到了同一封停兵告示。
- **官渡 · 粮队还在路上**：有个运粮人照着两张签拉回替换的空车。他最想问的，是哪一条路还能接到没回来的赶车人。

### 三条“史实/创作/演义”边界

1. 史实帧必须带 source（书名＋卷篇）；创作帧与演义帧不许带史实断言。
2. 创作对白绝不写回战果；只有玩家抉择才写回 `state`。
3. 事件链只由本局实际处境触发（仓粮、民心、战报、使节、俘虏），不凭空编剧情。
