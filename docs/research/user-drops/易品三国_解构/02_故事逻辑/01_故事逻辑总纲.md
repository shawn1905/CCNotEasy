# 故事逻辑总纲


## 一句话内核

**汉末秩序崩解后，粮、令、名分、信息、人心同时稀缺；每个历史节点都是一个“史料没写、但当事人必须决定”的缺口。玩家补上决定，系统用资源与关系结算后果，史书留下结果，游戏留下过程。**

它不是“英雄如何打天下”，而是“结构如何逼人做选择”。

## 故事逻辑的四层

1. **史实骨架**：5 个剧本、37 帧正史疆域、30 条年表、16 个历史大事件，负责给出时代坐标与硬约束。
2. **局势因果**：粮道、军令、民心、世族、名分、情报、关系、忠诚彼此咬合，负责让“为什么崩”有迹可循。
3. **史事推演**：28 个黄巾史线节点、7 个荆州史线节点、官渡两营、7 个独立推演，把史料空白翻译成三次互斥选择。
4. **账本收束**：战报、分支纪事、天下纪事、疆域回放、谥号，负责把一局的选择写成“史评”。

## 故事的最小单元

```text
史实事实（带出处）
  → 史料空白（一个必须回答的问题）
  → 三个互斥选择（每个都有代价）
  → 延迟/部分回执（不立刻告诉你对错）
  → 一个具体人的一隅（拟写，收束情绪）
```

例子：

- **长社**：史书只记皇甫嵩、朱儁、波才和战果。游戏问：“城外只听得到身边传话时，谁能核实道路，谁又肯接过送来的人？”
- **官渡**：史书只记荀彧劝留、许攸来投、乌巢被袭。游戏问：“一个可能正确的消息，值得用多少时间去查？等到完全把握时，原来的机会还在吗？”
- **湘水**：史书只记孙权索地、双方相拒、以湘水为界。游戏问：“双方都要腾出手应付别处的威胁时，你能提出什么让对方也愿意履行的承诺？”

## 因果引擎

| 变量 | 在故事里代表什么 | 典型后果 |
|---|---|---|
| **粮** | 时间、承诺、能不能继续围城 | 断粮 → 逃兵、民心崩、卖城、求和 |
| **军令** | 这个月能做几件事 | 用不完作废，逼你每月取舍 |
| **名分** | 谁有资格发号施令 | 奉天子 vs 称帝；称帝后诸侯好感骤降 |
| **信息** | 你看到的不是真相 | 驿报延迟、细作被识破、商旅风闻与细作报告对不上 |
| **关系** | 联盟、婚姻、质子、背盟 | 盟友求援、倒戈、复仇、称臣、纳土 |
| **民心/世族** | 统治成本 | 火攻屠城短期得利，长期谥号“炀”；世族不背书不能受禅 |
| **忠诚/志向** | 人物弧线 | 低忠诚 → 拒战、弃主、自立、叛变 |

## 分支与结局的逻辑

- 历史大事件是**条件触发**，不是按年份硬播：曹操控制许昌且屯田 → 屯田制；曹丕控制天子且汉室未亡 → 代汉 → 刘备称帝 → 孙权称帝；三回合内连下三城 → 诸侯震恐；同一势力三回合内丢两城且只剩 ≤3 城 → 可能求和；汉室灭亡 → 称帝门槛从 12 城降到 8 城。
- 结局不只有胜负：一统天下、基业尽失、6 种“功业”提前收束、以及最后的**谥号**。
- 谥号是道德审判：火攻多 → “炀”；背盟多 → “缪”；灭国多 → “武”；民心高且不焚城 → “文”；却寇多 → “桓”；单挑多 → “壮”；败亡则按存活回合数给“殇/愍/哀”。

## 叙事伦理：史实、创作、演义三色分离

代码里写死的三条规矩：

1. **史实帧必须带 source（书名＋卷篇）；创作帧和演义帧不许带史实断言。**
2. **创作对白不写回战果；只有玩家抉择才写回 state。**
3. **事件链只由本局实际处境触发（仓粮、民心、战报、使节、俘虏），不凭空编剧情。**

因此文本里会明确出现：

- “史载参照（非本局战报）”
- “当事人一隅（拟写）”
- “演义人物”
- 桃园结义标“文学演义”，五虎将标“后世合称”
- 华雄、祖茂、马腾、曹豹等条目注明“《演义》改作/非本传”

## 可复用的套路

找一个史料没写透的历史缺口 → 把它翻译成资源约束 → 给三个都合理的坏选择 → 让后果延迟到达 → 用一个普通人的视角收尾。

如果只记一句：**它把“历史”当成一套约束条件，把“故事”当成人在约束下留下的账。**

## 结局与评价

### 终局

| 类型 | 条件 | 叙事含义 |
|---|---|---|
| 一统天下 | 实控全部城池与军事关隘（险道不计） | “天下大势，合久必分，分久必合。” |
| 基业尽失 | 失去全部据点 | “胜败乃兵家常事，卷土重来未可知。” |
| 继续治理 | 统一后可选择继续 | 不结束对局，转入治理。 |
