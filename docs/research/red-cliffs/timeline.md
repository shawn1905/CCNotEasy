# 赤壁前夜时间线（建安十三年）

> 本切片关注「前夜」：自曹操得江陵至决战前的抉择窗。  
> 月序以《三国志·武帝纪》为主干；《通鉴》等异说单列，不抹平。

## 决战前夜窗口（设计用）

对玩家而言的「赤壁前夜」可落在：

1. **江陵决策窗**：东下与否、休整多久、水军与北兵如何配、降众如何用  
2. **东下途中 / 初遇前**：疾疫已现与否、是否轻敌、是否连船、是否受降诈  
3. **初战不利后、火攻前**：退守江北、对峙乌林、是否接受「诈降」、是否继续打  

具体事件卡片见 `facts.md`；可玩两害见 `tensions.md`。
