## 1. 资源联动（硬规则）

**顶栏数字不是装饰。** 钱帛 / 粮草 / 兵力每次变动，必须同时满足：

1. **当面理由**：在结算前 1～2 条气泡里，有人用白话把「钱/粮/兵为什么少（或多）」说清楚。  
2. **因果可指**：理由对应具体动作（发赏、开拔、隔离、造船铁索、赏赐降人……），禁止「选了就扣」的无声扣分。  
3. **结算可见**：选项确认后，用一条短系统气泡或顶栏跳字，复述同一理由，例如：`粮草 -1 · 东下水军开拔，先吃掉江陵一旬漕运`。

写选项表时强制三列：`effects` + `reason`（给人看的一句）+ 对话里已埋伏笔。

```text
反例：选 A → 粮草-1（旁白不提）
正例：管粮吏：「开拔得先扣一旬漕运。」→ 玩家选东下 → 「粮草-1 · 开拔扣一旬漕运」
```

兵力同理：减员要说病、逃、分屯、战损；加兵力要说整编、征发、虚报（虚报须标明是账面）。

## 2. 全局注释（点击解释）

### 做什么

- 气泡里难懂的**引文、典故、制度词、夸张数字**可点。  
- 点开：**一句话白话** + 可选「出处/史载」一行；不跳转长文。  
- 全局同一词条共用一份注释表（`gloss`），避免每句重复解释。

### 不做什么

- 不给整段白话文平行轨（破坏节奏）。  
- 不把注释写成攻略（「选这个会赢」）。  
- 演义/拟写句子若不难懂，不必强行加注。

### 文案标记（剧本阶段）

```markdown
外面开始传「水军八十万」{{gloss:eighty_wan}}。
```

```json
// content/gloss.json
{
  "eighty_wan": {
    "term": "水军八十万",
    "plain": "恐吓用的夸张说法，不是精确点兵名册。",
    "source": "《通鉴》等载曹操遗孙权书传统"
  }
}
```

UI：词下浅底线或虚线；点按弹出 Tokyo Night 风格小面板（方正、短）。

### 哪些必须考虑加注

- 直接引用或半引用的古句（如会猎、盛寒马无藁草）  
- 官职/制度（丞相、侯者十五人、蒙冲斗舰）  
- 易误解的数量词（八十万）  
- 地名简称若可能懵（柴桑、夏口）——首见加注，再见可不注
