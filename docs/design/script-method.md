# 剧本优先方法论（赤壁前夜 Demo）

```
确认意向：2026-11-26 Asia/Shanghai
优先级：趣味性 > 剧本完成度 > 交互壳 > 视听抛光
事实权重：公开史料第 1 · 朋友易品看法/调性第 2
```

## 1. 这句话定调

Demo 不是「把赤壁百科点一点」，而是让玩家在丞相府里**连续踩两害**，一边被史实选项哄进去，一边在旁支里吃到更有味道（往往更苦）的内容。

**好玩**在本项目里拆成四件事：

| 趣味零件 | 玩家感觉 |
|----------|----------|
| 两害咬合 | 「两个都不舒服，但我非选不可」 |
| 诱向反转 | 「明明大家都让我选 A，选了才发现……」 |
| 马伯庸口气 | 当代节奏讲古事，笑点不拆史架 |
| 延迟回执 | 当下只给你半个结果，下一段才砸下来 |

UI 丝滑、换肤、音效都服务这四件事，不单独抢戏。

## 2. 最小故事单元（改编自朋友稿 + 生命线）

朋友易品的单元是「三选一 + 延迟回执」；我们切片是 **二选一气泡**，单元改成：

```text
① 史实锚点（facts 一条，可不出示给玩家）
② 史料缺口（一句戏剧问题——府里此刻非答不可）
③ 两害选项
    · A 史实诱导向（暗示、附和、短利可见）
    · B 旁支真内容（更脏/更痛，结局不必快乐）
④ 即时半回执（气泡里只露代价的一角）
⑤ 延迟账单（2～4 个气泡后再结算：资源 + 战报/人物一隅）
```

写的时候禁止：一边是「明显正确」、一边是「傻子选项」。两边都要能自圆其说。

## 3. 工作顺序（严格剧本先行）

```text
Step 0  母题句（一节一句）
        例：绝对优势为什么会失效？

Step 1  节脊（Spine，半页）
        开场处境 → 4 个两害节拍 → 战报 → 2～3 个结局收束
        本 demo 默认节拍：T-01 → T-04 → T-05 → T-06
        （江陵东下 / 疾疫 / 连船 / 诈降）

Step 2  节拍卡（每张 T 一页）
        戏剧问题 / A·B 文案意向 / 资源 delta /
        诱向手法 / 延迟账单接到哪 / 趣味自检

Step 3  对话本（可直接念的气泡稿）
        按生命线短句；标注 史载|拟写|演义
        先写「史实诱导向通关」一条金线，再写旁支分叉

Step 4  你听一遍 / 改趣味
        出声读；笑点与恶心点不到位就改字，不改引擎

Step 5  才落 JSON + 薄壳
        scenes/*.json 挂引擎；UI 只负责把字送进耳朵
```

**在 Step 4 通过前，不优先扩框架、不优先换肤、不上真 LLM。**

## 4. 节脊模板（本 demo）

| 序 | 节拍 | 戏剧问题（草案） | 趣味钩子 |
|----|------|------------------|----------|
| 0 | 开场 | 江陵在手，你要的是速度还是命？ | 胜利后的虚胖 |
| 1 | T-01 | 东下会猎，还是再抚降众？ | 众谋士起哄东下 |
| 2 | T-04 | 疫报压住，还是摊开减员？ | 「八十万」话术的笑话 |
| 3 | T-05 | 连船稳阵，还是分屯防火？ | 晕船北兵 vs 南人笑 |
| 4 | T-06 | 受降立观，还是远泊强弩？ | 最大的诱向 + 最响的耳光 |
| 5 | 战报 | 一页结算 | 马伯庸式战报口吻 |
| 6 | 收束 | 2～3 结局 | 史实灰 / 旁支苦赢 / 旁支惨 |

旁支不是「另一本百科」，是**同一条江上更疼的活法**。

## 5. 趣味自检（每张节拍卡过一遍）

写完一张卡，问：

1. **两害？** 删掉「正确感」后是否还难选？  
2. **诱向？** 没玩过的人会不会被推向 A？  
3. **一句能转述？** 玩家会不会跟别人讲「我当时选了…结果…」？  
4. **口气？** 像丞相府夜谈，不像说明书？  
5. **史架？** 事实冲突是否仍让位公开史料？

五条里两条「否」→ 先改剧本，不进引擎。

## 6. 和现有库存的接法

| 库存 | 用法 |
|------|------|
| `facts.md` | ① 的锚，不直接当台词 |
| `tensions.md` | Step 1～2 的题库 |
| 易品总纲 / 推演 | 调性、缺口问法、延迟回执；**视点改写成曹操府** |
| Lifeline 交互稿 | Step 5 的呈现，不反向决定剧情 |
| Tokyo Night | 读剧本时的皮肤，不参与编剧 |

## 7. 交付物（剧本阶段）

```text
docs/content/red-cliffs-eve/
  SPINE.md           ← 节脊
  beats/T-01.md …    ← 节拍卡
  script.md          ← 全节对话本（金线+旁支）
  endings.md         ← 收束
```

过你耳后再 `content/scenes/*.json`。
