# 剧本优先方法论（赤壁前夜 Demo）

```
确认意向：2026-11-26 Asia/Shanghai（修订：同日夜，严肃考据优先）
优先级：史料填满 > 逻辑推演 > 两害戏剧 > 剧本完成度 > 交互壳 > 视听抛光
事实权重：公开史料 A/B 第 1 · 逻辑推演 C 第 2 · 朋友易品结构/看法第 3
文风配额：全篇 10 分里，严肃考据+逻辑细节 ≥ 9；马伯庸式幽默/俏皮 ≤ 1
```

## 1. 这句话定调

Demo 不是段子集，也不是百科点击器。玩家在丞相府里**连续做两害抉择**；每个抉择必须能指回 `docs/research/red-cliffs/timeline-sourced.md` 里某条**史料缺口**，用史实压力与逻辑代价推进，而不是用俏皮话推进。

**好玩**在本项目里拆成四件事（排序即权重）：

| 零件 | 玩家感觉 | 配额 |
|------|----------|------|
| 史实压力 | 「这不是作者编排，是江上真有的账」 | 主菜 |
| 逻辑展开 | 「选了会怎样，链条说得清」 | 主菜 |
| 两害咬合 | 「两个都不舒服，但我非选不可」 | 主菜 |
| 诱向反转 / 延迟回执 | 「短利可见，账单后到」 | 主菜 |
| 马伯庸式幽默 | 偶有一口冷幽默，**不拆史架、不抢戏** | ≤ 1/10 |

**禁止：** 为文风放弃史实；先写金句再找史料贴金；把「晕船故连船」等无 A 层出处的流行说写成史载。  
**允许：** 说话狠、冷、短；狠 ≠ 段子。

UI 丝滑、换肤、音效只服务上述零件，不单独抢戏。

## 2. 最小故事单元（改编自朋友稿 + 生命线）

朋友易品的单元是「三选一 + 延迟回执」；我们切片是 **二选一气泡**，单元改成：

```text
① 史实锚点（facts 一条，可不出示给玩家）
② 史料缺口（一句戏剧问题——府里此刻非答不可）
③ 两害选项
    · A 史实诱导向（暗示、附和、短利可见）
    · B 旁支真内容（更脏/更痛，结局不必快乐）
④ 即时半回执（气泡里只露代价的一角）
⑤ 延迟账单（2～4 个气泡后再结算：资源 + 战报/人物一隅）
```

写的时候禁止：一边是「明显正确」、一边是「傻子选项」。两边都要能自圆其说。

**资源硬规则：** 减（或加）钱帛/粮草/兵力，必须先在对话里说清理由，结算时再复述；禁止无声扣分。详见 `annotations-and-resources.md`。

**注释：** 难懂引文用 `{{gloss:id}}`，全局点击解释。

## 3. 工作顺序（严格：史料 → 推演 → 剧本）

```text
Step 0  母题句（一节一句）
        例：绝对优势为什么会失效？

Step 0.5 史料时间线填满（强制）
        docs/research/red-cliffs/timeline-sourced.md
        每节点：原文 → 可确认 → 未答缺口 → 仅在缺口上 [C] 推演
        未完成本步，禁止开写对话俏皮稿

Step 1  节脊（Spine，半页）
        开场处境 → 4 个两害节拍 → 战报 → 2～3 个结局收束
        本 demo 默认节拍：T-01 → T-04 → T-05 → T-06
        （江陵东下 / 疾疫 / 连船 / 诈降）
        每一拍必须标注锚定的 sourced 节点编号

Step 2  节拍卡（每张 T 一页）
        史料锚 / 缺口问题 / A·B 利害（逻辑，非段子）/
        资源 delta 与说理 / 延迟账单 / 史实自检

Step 3  对话本（可直接念的气泡稿）
        短句；标注 [史载]|[B注]|[拟写]|[C推演]
        先把利害与史实说清；幽默整节合计不超过约一成篇幅
        先写「史实诱导向」金线，再写旁支分叉

Step 4  你听一遍 / 改深度
        出声读；缺史实、缺因果就改字；不要靠加笑点补深度

Step 5  才落 JSON + 薄壳
        scenes/*.json 挂引擎；UI 只负责把字送进耳朵
```

**在 Step 0.5–4 通过前，不优先扩框架、不优先换肤、不上真 LLM。**

## 4. 节脊模板（本 demo）

| 序 | 节拍 | 戏剧问题（草案） | 趣味钩子 |
|----|------|------------------|----------|
| 0 | 开场 | 江陵在手，你要的是速度还是命？ | 胜利后的虚胖 |
| 1 | T-01 | 东下会猎，还是再抚降众？ | 众谋士起哄东下 |
| 2 | T-04 | 疫报压住，还是摊开减员？ | 「八十万」话术的笑话 |
| 3 | T-05 | 连船稳阵，还是分屯防火？ | 晕船北兵 vs 南人笑 |
| 4 | T-06 | 受降立观，还是远泊强弩？ | 最大的诱向 + 最响的耳光 |
| 5 | 战报 | 一页结算 | 账本口吻：读回 flag 与史料后果，少俏皮 |
| 6 | 收束 | 2～3 结局 | 史实灰 / 旁支苦赢 / 旁支惨 |

旁支不是「另一本百科」，是**同一条江上更疼的活法**。

## 5. 自检（每张节拍卡过一遍）

写完一张卡，问：

1. **史料锚？** 能否指回 `timeline-sourced` 某节 A/B？有无把 `[C]` 写成史载？  
2. **缺口？** 两害是否长在「史料未答」上，而非长在金句上？  
3. **逻辑？** 资源变动与后果链条是否说得清（有理由，非气氛扣分）？  
4. **两害？** 删掉「正确感」后是否还难选？  
5. **诱向？** 短利是否可见，且不靠嘲讽旁支成傻子选项？  
6. **文风？** 本节俏皮/幽默是否明显少于一成？删掉笑点后史实压力是否还在？

六条里两条「否」→ 先改资料或节拍，不进引擎。

## 8. 从 GitHub 补上的编剧手艺（不会编也按清单走）

公开仓库里可直接偷师的，已筛进本 demo 用法：

| 来源 | 偷什么 | 我们怎么用 |
|------|--------|------------|
| [ericrisco branching-and-state](https://github.com/ericrisco/rsc-harness/blob/main/skills/game-storytelling/references/branching-and-state.md) | **Foldback（串珠）**：分叉后再汇合；有意义选择三腿（意图/可预见/后果落地）；**可假结果，不可假赌注**；延迟后果要有 callback | 四节拍之间用汇合点；T-06 等「真赌注」必须读回 flag；半回执 + 「因为你当时…」 |
| 同上 | 防爆炸：汇合、门闸、**状态优于复制场景**、结局用摘要变量 | 4 个二选一不全树展开；结局只看 2～3 个摘要轴（如 `haste` / `plague_honesty` / `fire_posture`） |
| [Stanestane/narrative-design-skills](https://github.com/Stanestane/narrative-design-skills) | 选择审计：假能动性、劣势选项、弱反馈、状态失忆；场景先目标/阻力/转折再写台词 | 节拍卡多一栏「选择审计」；对话本前先填戏剧目标 |
| [BranchGuard checklist](https://github.com/ExpectooPatronum/branchguard-narrative-qa-checklist) | 十分钟预检：跳转、可达、结局终端、无死胡同 | `script.md` 定稿后跑一遍手检 |

### 本 demo 强制结构 = Foldback

```text
开场
  → T-01 分叉 → 汇合「疫报到案」
  → T-04 分叉 → 汇合「要不要连船」
  → T-05 分叉 → 汇合「有人来降」
  → T-06 分叉 → 战报（读摘要变量）→ 2～3 结局
```

旁支不是另开一本长篇，是**同一珠串上换台词/资源/战报口气**；只有少数 flag 进结局。

### 有意义选择（写选项前默念）

1. 玩家是否知道自己想选哪边（意图）  
2. 是否想得出大概会怎样（可预见，允许事后打脸）  
3. 后面是否**读回**这次选择（落地；否则删掉或降成纯语气）

诱向史实 = 短利可见 + 谋士起哄；**不许**做成「A 正确 / B 弱智」。旁支若汇合，也要用气泡/资源承认赌注，禁止静默同结局。

### 节拍卡加一栏（补进 Step 2）

```text
选择审计：有意义？非劣势项？即时反馈？延迟 callback 接到哪？
摘要变量：本拍写入哪个（如 haste+=1）
```

## 9. 下一步（等你一句「按这个写」）

1. 写出 `SPINE.md` + 四张节拍卡（先不写满气泡）  
2. 你点哪张「不够好玩」就改哪张  
3. 再铺 `script.md` 金线全文  
4. BranchGuard 式手检 → 再脚手架挂字
