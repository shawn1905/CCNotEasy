# 交互逻辑参考：《生命线》Lifeline（已确认）

> 用于《曹操不容易》赤壁切片。Omarchy 气质 + 手机优先。  
> 日期：2026-11-26（Asia/Shanghai）

## 采纳

| 点 | 做法 |
|----|------|
| 主界面 | **聊天气泡流**（对方叙述 / 请示 → 你回执） |
| 抉择 | 关键节点 **二选一**（可扩展为少选项，默认俩） |
| 节奏 | 短句、一条条出来；适合单手拇指 |
| 沉浸 | 像「有人在对面等你拍板」，不是 RPG 菜单墙 |
| 资源 | 顶栏极简显示钱帛/粮草/兵力；**变动必须有当面理由 + 结算复述**（见 `annotations-and-resources.md`） |
| 注释 | **全局可点释义**：难懂引文/制度/夸张数字 → 一句话白话（`{{gloss:id}}`） |

## 刻意不照搬

| 点 | 原因 |
|----|------|
| 强制现实时间等待 | 与「一节 10–15 分钟可清」冲突 |
| 推送强依赖 | 网页切片先不做系统推送 |
| 纯现代 IM 皮肤 | UI 走 Omarchy/中国风终端感，不是微信换皮 |

## 本项目变体（已落地 · 决策台）

1. **连点推进**为默认；可选「沉浸等待」开关（后置）  
2. 气泡角色：曹操府内请示者 / 军报 / 密信——仍是对话流，不切立绘场景  
3. **拍板前决策台**（四难）：短铺垫后出现 desk——**走动**看环境、**问策**听谋士、**翻卷**开史料；不强制做完，再点「准备拍板」出 A/B  
4. 选项上可轻标「众望所归」类暗示（**诱向史实**），不写死「正确」  
5. 战报结算：仍塞进对话流（一页战报气泡或全宽卡片）  
6. 信息默认不灌满：没走访/没问过的内容，不会自动替你说完
