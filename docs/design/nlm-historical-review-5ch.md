## 二、高含金量正史细节补强（最适合写进柜台假账与两难！）

1. **赤壁**：
   - **急性血吸虫病 40 天潜伏期**（深秋南下钉螺区，恰在冬月决战集体高热腹泻爆发）；
   - **云梦泽冬月「湖陆风」**（解释东南风的自然气象逻辑）；
   - **合肥「蒋济伪信心理战」**（张喜千骑染疫，蒋济故意让吴军截获「步骑四万至零阳」假信吓退孙权——极适合做案叁高光柜台！）。
2. **官渡**：
   - **许都—颍水/汴水粮道 + 后方汝南刘辟叛乱**（断粮不是纯数字，是后方坞堡体系总危局）；
   - **乌巢伪装谍战**（人衔枚、马缚口，遇盘查诈称「袁公恐曹操钞略后军，遣兵益备」，精准打在袁绍未听沮授派蒋奇策应的漏洞上）。
3. **宛城**：
   - **借口春季避湿「车重移营」**完成近距离合围，造成曹营各不相救；
   - **丁夫人决裂离异 → 卞夫人扶正 → 曹丕曹植储位之争**的家族法统蝴蝶效应！
4. **白门楼**：
   - **陈宫「掎角之策」因吕布妻猜忌（陈宫高顺不和）流产**的内斗细节；
   - **真正神来之笔：招抚臧霸等泰山豪霸锁死青州袁谭南下通道**（比收吕布更具正史策略深度！）。
5. **汉中**：
   - **杜袭、张既战略焦土与内迁数万户及五万氐人**（留给刘备一座十室九空的空壳汉中）；
   - **八月大霖雨汉水暴涨五六丈（水淹七军气象真相）+ 邺城「魏讽谋反案」牵连名士**（逼出司马懿、蒋济密联孙权的真正底层压力！）。
